Create or fully replace a UTF-8 text file.

Defaults to overwrite, replacing the whole file. For 100+ lines, split into multiple calls and append after the first write. For targeted changes, prefer edit.

Conflict resolution: file_path accepts conflict://<N> to resolve one registered block or conflict:// to resolve all. Content may use @ours / @theirs / @base / @both line tokens. Regular writes refuse when content still holds conflict markers; pass allow_conflicts=True to override.

Auto-generated guard: overwriting/appending to a file that looks machine-generated (zz_generated., .pb.go, _pb2.py, .gen.ts, .swagger.json, or an @generated / Code generated by header) is refused — edit the source and regenerate, or pass allow_auto_generated=True.

Safety: successful writes record pre/post snapshots and bust stale filesystem caches, so a mistaken overwrite stays recoverable within the session.
