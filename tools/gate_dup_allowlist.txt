# G-DUP allowlist — `tools/gate_dup.py`
#
# A model-facing tool name with more than one implementation is a divergent
# duplicate unless waived here.  Waive only when the implementations are
# intentionally distinct (with contrast probes) or one is a thin delegator
# proven by a parity test.  Syntax:  name  # rationale

# kimi_cli `AgentTool` (name "subagent") and kimix `Agent` (name "subagent") are
# deliberately distinct tools: run_in_background defaults to False in C01 and
# True in K01, and the plan mandates a contrast probe in both gate blocks
# (§4.4 C01 probe 5, K01 probe 3).  They are not delegators, so no parity test
# can collapse them — the divergence is the contract.
subagent  # intentionally distinct C01 (fg default) vs K01 (bg default); contrast probes mandated

# regress a working transport.

# documents `fetch_url` with exactly K14's `url`/`output_path` signature, and
# `:982` documents `fetch_to_markdown` as the Playwright helper, so the name
# `fetch_url` is load-bearing for the kimix stack's documented API.
#
# The two are parallel implementations for two disjoint runtimes - the same
# situation as `subagent` below.  Divergence cannot silently drift because
# `tests/test_fetch_url_parity.py` pins both contracts.
fetch_url  # parallel impls for disjoint runtimes (aiohttp vs Playwright); delegation impossible, name documented
